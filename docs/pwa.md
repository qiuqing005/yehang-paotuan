# PWA 安装说明

本项目已补齐基础 PWA 安装资源：`manifest`、`service worker`、安装图标、Windows 磁贴配置与快捷方式。

## Android

推荐使用 Chrome 或 Edge：

1. 打开站点首页。
2. 等待页面加载完成，地址栏右侧出现安装提示时点击“安装”。
3. 如果没有自动提示，打开浏览器菜单，选择“安装应用”或“添加到主屏幕”。

安装后会以独立窗口启动，桌面图标和快捷方式来自 `site.webmanifest`。

## Windows

推荐使用 Edge 或 Chrome：

1. 打开站点首页。
2. 在地址栏右侧点击安装图标，或打开浏览器菜单选择“安装此站点为应用”。
3. 安装完成后可固定到任务栏、开始菜单或桌面。

Windows 侧会读取 `manifest` 图标；兼容磁贴场景时会回退到 `browserconfig.xml` 中的磁贴资源。

## 移动端信息架构

Android 端底部只保留三个高频入口：

- 地图：默认首屏，包含房间切换、场景地图、棋子移动和语音胶囊。
- 聊天：团内发言、行动记录和系统事件。
- 角色：角色状态、HP / SAN 调整和角色说明。

房间管理不占底部导航，放在地图页顶部“切换房间”。语音不占独立页面，使用全局浮动胶囊，避免打断看地图和聊天。

## 检查点

- `Application > Manifest` 中能看到应用名、主题色、图标和快捷方式。
- `Application > Service Workers` 中能看到 `sw.js` 已注册并激活。
- Android/Windows 安装入口可见，安装后能以独立窗口启动。
